**必须**加载 `ironlaw-gate` 技能。

按「门禁七要素」逐条确认后再写代码：

1. **判据单一真源** —— 一个 `evaluate()` 函数，正式扫描和自证共用同一份判据。
2. **缺数据 fail-closed** —— 目录不存在、文件读不到、扫描到 0 个文件，都必须判红，不许当成「没问题」。
3. **自证（`--selftest`）** —— 用合成夹具证明：干净样本放行、脏样本判红、边界样本按预期处理。
4. **反向探针** —— 用 `scripts/reverse-probe.mjs` 证明「改坏 → 必转红」，并 md5 逐字节复原。
5. **注册进聚合器** —— 不注册的门禁等于不存在。
6. **失败输出可归因** —— 打印出具体文件:行号:原因，而不是只报一句「检查失败」。
7. **EXIT 码四态** —— 0 通过 / 1 判据红 / 2 设施或配置错误 / 3 SUSPECT（全量红但单跑绿），不许把超时伪装成通过或判据失败。

可以直接从 `assets/guard-skeleton.mjs` 复制起步，通常只改 `RULES` 数组（规则表）即可；判据结构特殊时再改 `evaluate()`。

写完**必须**跑一次 `--selftest` 和一次反向探针，两个都过才算完成。
